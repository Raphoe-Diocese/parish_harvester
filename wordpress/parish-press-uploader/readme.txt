Full Parish Press Uploader (the 16_0 file) plus a Settings link on the Plugins page.

== Which zip ==

Parish-Press-Uploader-16_0.zip is the complete plugin (side menu, upload page, bulletin links).
Parish-Press-Uploader-15.0.8.9.1.zip is newer by date but cut off — no side menu.

This folder is 16_0 with Settings added. Version 16.0.1.

== Install on an existing site ==

1. Plugins → Deactivate the old Parish Press Uploader. Do not delete wp-content/uploads/parish-bulletins.
2. Plugins → Add New → Upload Plugin → parish-press-uploader-16.0.1.zip → Activate.
3. Settings → Permalinks → Save Changes once.
4. Left menu → Parish Press. Plugins row now has Settings.
5. Wordfence can stay on.
