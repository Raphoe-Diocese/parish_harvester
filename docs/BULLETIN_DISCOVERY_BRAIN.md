## Reusable discovery playbooks (retain for future agents)
1. **MCN Live:** From a church's camera page identify its numerical church ID; request `POST /Website/ProfileDataByJson/{church_id}`; read `newsletter.newsLetterUrl`, validate HTTP/PDF bytes, extract masthead date and compare hashes with previous harvest. MCN's CloudFront `/live/Uploads/{church_id}/NewsLetter/{uuid}.pdf` is an *ephemeral output*, not a stable recipe URL. Browser download is fallback. Example: Glenfinn church ID **164**; Falcarragh **403**; Dunfanaghy **424**; Kilcar **652**; Killybegs **115**; Glencolmcille **661**; Donegal Town **171**; Inver/Frosses **527**; Gneeveguilla **620**; Dingle **394**; Rathmore **200**; Armoy **660**; Loughgiel **317**; Portarlington **354**; Edenderry **434**; Ballyhaunis **22**.
2. **Google Drive:** Discover file/folder IDs from parish website; for a single file, check changing file content and actual issue date at a stable ID; for folders, enumerate candidate PDFs and rank by *printed bulletin date*. Avoid pinning a snapshot without freshness verification. Leads: Gartan/Termon file `1KnA8F6t54NmbyeitUGgtfWxN2IqFMDOa`; Burt folder `1RjeEY_AYy62pRNWmVmDeINfHVqkPyCsw`; Bruckless file `1h5KwZ--cqO0L5grXlAaerMwmyOLFgqkN` and folder `1jPOi4GRU22vAxeKNe5Y_doBJ3riPh7ZK`; Glenties file `14aLAxt4mv7eYBvYx2GGthpsQnLrsysmK`; Irish Martyrs file `1m6sOGz3dECWvbbpXCnRGdHG77yWiLXxR`; Raphoe file `1jmslbrliw1BTtdrxHbqpUbhQEf6wXHy5`; Templecrone file `1Hh7w-Ew0vLJUFMihFiVzVJGhjeYposIH`.
3. **WordPress:** Crawl newsletter/bulletin archive links; parse dates from title, URL and PDF masthead; choose newest credible issue; never retain an old `href` or date-specific `download.url` in the weekly recipe. Example: Kincasslagh.
4. **onewebmedia:** List linked files and resolve filenames (PDF and DOCX); convert DOCX only where permitted and confirm printed date. Leads: `https://www.limavadyparish.org/onewebmedia/`, `https://www.lisnaskeamaguiresbridgeparish.com/onewebmedia/`, `https://www.galloonparish.com/onewebmedia/`, `http://parishofclaudy.com/onewebmedia/`.
5. **Churchmedia/ChurchTV:** Look for newsletter endpoints and dynamically discover latest URL. Examples: `https://churchmedia.tv/newsletter/d5sq6l.st-patricks-church-2.pdf`, `https://churchmedia.tv/newsletter/px2ika.st-columba.pdf`, `https://www.churchtv.ie/crossmolina/`.
6. **Parishpress permanent PDF:** Test stable `bulletin.pdf` URLs using byte and text hashes plus masthead date; never infer freshness from same URL. Leads: `https://www.parishpress.net/wp-content/uploads/parish-bulletins/donegal/raphoe/drumholm-parish/bulletin.pdf`, `https://www.parishpress.net/wp-content/uploads/parish-bulletins/donegal/raphoe/gort-a-choirce/bulletin.pdf`.
7. **Canva/JS sites:** Render or inspect network/API responses; extract genuine newsletter document links. Lead: `https://ardboeparish.my.canva.site/website`.
8. **Shared family-of-parishes sites:** One newsletter page may serve multiple parishes; deduplicate by content hash and map the correct parish names. Examples: `https://onefaith.ie/newsletter`, `https://parishestogether.ie/notices/newsletters`, `https://bantryfamilyofparishes.ie/notices`, `https://corkcathedralfop.ie/notices/newsletter`.
