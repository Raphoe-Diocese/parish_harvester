## Shared-bulletin publication contract (20 November 2026)

**One publication can serve several parishes.** The repository's canonical source-of-truth for confirmed parish aliases is `harvester/parish_aliases.py::ALIAS_TO_CANONICAL`, while `docs/discovery/verified-mcn-church-identities.json` records MCN **church** identities which share a parish issue. These have different meanings: a second church/camera does **not** imply a second independently published newsletter.

Harvest one actual current document from the canonical source. Display the canonical parish with all verified shared-parish names and link those places to **the same** reader/download. Count the verified source publication only once; never inflate download or missing counts because the parish covers more than one church. Conversely, don't delete a genuinely separate weekly publication merely because a neighbouring parish, shared web host, or family-of-parishes site is involved. Check content SHA-256 and issue masthead dates; a shared domain, file length or similar title is insufficient evidence. A long document and an HTML/image bulletin can be legitimate.

Reporting rule: when canonical and alias both produce **proven identical** PDFs (matching SHA-256, Drive file ID or exact URL without contradictory hashes/dates), keep one canonical download and preserve `shared_bulletin_coverage` and `shared_download_aliases`. Different hashes or issue dates must stay separate for investigation. An alias-only download is flagged in `alias_downloads_without_canonical` because the mega-PDF stitcher skips alias keys: don't claim that parish is included in the combined publication until the canonical issue is genuinely available.

Examples: Gartan/Termon–Kilmacrenan; Drumholm–Ballintra; Milford–Rathmullan; Ballycastle–Armoy–Ballintoy; Mohill–Fenagh–Gortletteragh. MCN shared cameras Aclare–Tourlestrane and Gneeveguilla–Rathmore are documented in the identity registry. **Never infer new shared groups without independently verified source evidence** and add each new rule here, to the structured registry/mapping and to regression tests.
