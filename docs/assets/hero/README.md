# Homepage hero slider images

The homepage (`docs/index.html`, generated by `_landing_page()` in
`harvester/site_builder.py`) has a rotating image slider at the top. Right
now it uses elegant CSS-gradient "slides" with overlaid text as placeholders
— no real photos have been supplied yet.

## Swapping in real photos

1. Drop your image files in this folder (`docs/assets/hero/`), e.g.:
   - `docs/assets/hero/slide-1.jpg`
   - `docs/assets/hero/slide-2.jpg`
   - `docs/assets/hero/slide-3.jpg`
2. Open `harvester/site_builder.py` and find the `HERO_SLIDES` list near the
   top of the file. Each entry looks like:

   ```python
   HeroSlide(
       image=None,  # <- set to "assets/hero/slide-1.jpg" to use a real photo
       gradient="linear-gradient(135deg, #114b4b 0%, #1a6b6b 55%, #2f9e8f 100%)",
       eyebrow="Raphoe · Derry · Down & Connor",
       title="Parish bulletins, all in one place",
       subtitle="Auto-collected every Sunday, free forever.",
   ),
   ```

3. Set `image` to the relative path from `docs/` (e.g.
   `"assets/hero/slide-1.jpg"`). When `image` is set, the slide uses that
   photo (with a dark gradient overlay so the title text stays readable)
   instead of the plain CSS gradient.
4. Re-run the site builder (`python -c "from harvester.site_builder import
   run; run()"`) or just wait for the next scheduled harvest/OCR run — the
   homepage is regenerated automatically.

## Recommended image size

- **Aspect ratio:** wide, roughly 16:9 or 21:9 (the slider is short and
  wide, not a full-bleed hero banner).
- **Minimum width:** 1600px wide so it stays sharp on large/retina screens.
- **File size:** keep each photo under ~400KB (JPEG, quality ~75-85) so the
  homepage stays fast to load. Resize/compress before committing — nothing
  in the build pipeline does this for you.
- **Content:** parish exteriors, church interiors, or bulletin-board type
  photography all work well. Avoid photos with important detail near the
  very top/bottom edges — the overlay text sits in the lower-left corner and
  the image itself gets cropped to a wide letterbox shape on most screens.

## Notes

- Slides without a real photo just render as a tasteful colour gradient with
  the same text overlay — perfectly fine to ship as-is, this is only a
  cosmetic upgrade path for whenever real photos are available.
- The slider is plain CSS + vanilla JS (no framework, no external images or
  fonts loaded), auto-advances every 6 seconds, and pauses/skips animation
  entirely for visitors with `prefers-reduced-motion` enabled.
