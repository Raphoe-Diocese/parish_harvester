# Homepage hero slider images

The homepage (`docs/index.html`, generated by `_landing_page()` in
`harvester/site_builder.py`) has a rotating image slider at the top. It now
shows real photos of the Catholic cathedral for each live diocese,
hotlinked directly from Wikimedia Commons (see "Photo credits"
below for the exact source/license/author of each).

The images are hotlinked directly from `upload.wikimedia.org` (via each
file's `1280px-` thumbnail rendition, not the multi-MB original) rather than
committed into this repo — Wikimedia's CDN serves these reliably and it
keeps the git history free of large binaries. If you'd rather self-host any
of them (e.g. for offline builds or extra reliability), download the file,
drop it in this folder, and point `image=` at the local path instead — see
below.

## Swapping in your own photos

1. Drop your image files in this folder (`docs/assets/hero/`), e.g.:
   - `docs/assets/hero/slide-1.jpg`
   - `docs/assets/hero/slide-2.jpg`
   - `docs/assets/hero/slide-3.jpg`
2. Open `harvester/site_builder.py` and find the `HERO_SLIDES` list near the
   top of the file. Each entry looks like:

   ```python
   HeroSlide(
       image="https://upload.wikimedia.org/wikipedia/commons/thumb/.../1280px-....jpg",
       credit="Photo: Dieglop / Wikimedia Commons / CC BY-SA 4.0",
       gradient="linear-gradient(135deg, #0f3d3d 0%, #1a6b6b 55%, #3fae9a 100%)",
       eyebrow="Raphoe Diocese",
       title="Cathedral of St. Eunan and St. Columba, Letterkenny",
       subtitle="Auto-collected every Sunday, free forever.",
   ),
   ```

3. Set `image` to either:
   - a relative path from `docs/`, e.g. `"assets/hero/slide-1.jpg"`, for a
     file you've committed to this folder, or
   - a full `https://` URL to hotlink an external image (e.g. another
     Wikimedia Commons photo).
4. Set `credit` to a short attribution line if the photo's license requires
   one (any CC BY / CC BY-SA / etc. photo), or `None` if it's your own photo
   or public domain and you don't want a credit shown.
5. `position` (optional, defaults to `"center"`) is a CSS
   `background-position` value — useful for portrait/tall photos where the
   interesting part (e.g. cathedral spires) isn't in the vertical middle of
   the frame. For example `"center 20%"` biases the crop toward the top of
   the image.
6. Re-run the site builder (`python -c "from harvester.site_builder import
   run; run()"`) or just wait for the next scheduled harvest/OCR run — the
   homepage is regenerated automatically.

## Recommended image size

- **Aspect ratio:** wide, roughly 16:9 or 21:9 works best (the slider is
  short and wide, not a full-bleed hero banner) — but portrait/tall photos
  still work fine with `position` set to keep the interesting part in frame.
- **Minimum width:** 1600px wide so it stays sharp on large/retina screens.
- **File size:** keep each photo under ~400KB (JPEG, quality ~75-85) so the
  homepage stays fast to load. Resize/compress before committing — nothing
  in the build pipeline does this for you. (The 3 current Wikimedia hotlinks
  are already sized down to a 1280px-wide thumbnail rendition for exactly
  this reason.)
- **Content:** parish exteriors, church interiors, or bulletin-board type
  photography all work well. Avoid photos with important detail near the
  very top/bottom edges — the overlay text sits in the lower-left corner and
  the image itself gets cropped to a wide letterbox shape on most screens.

## Notes

- Slides without a photo (`image=None`) just render as a tasteful colour
  gradient with the same text overlay — a safe fallback if a hotlinked image
  ever goes offline, and a fine starting point for adding new slides.
- The slider is plain CSS + vanilla JS (no framework, no external fonts
  loaded), auto-advances every 6 seconds, and pauses/skips animation
  entirely for visitors with `prefers-reduced-motion` enabled.
